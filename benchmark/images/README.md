# Benchmark image set

Поместите сюда лицензированно доступные исходные фотографии в JPEG, PNG или
WebP. Файлы не включены в репозиторий намеренно: случайные изображения из
интернета создадут проблемы с авторскими правами и невоспроизводимый benchmark.

Минимальный набор должен содержать отдельные примеры следующих категорий:

1. человек в полный рост;
2. портрет с распущенными волосами на неоднородном фоне;
3. животное с заметной шерстью;
4. товар или бытовой предмет;
5. сложный тонкий контур (спицы, растение, сетка, провода);
6. объект и фон похожего цвета;
7. сложный, визуально загруженный фон.

Рекомендуется 5–10 изображений каждой категории, разные aspect ratio и
разрешения, включая хотя бы один JPEG с EXIF orientation, PNG и WebP. Не
используйте изображения с уже удалённым фоном для latency benchmark.

Запуск одной модели:

```powershell
python scripts/benchmark.py --device auto --repeats 3
```

Сравнение full и lite BiRefNet:

```powershell
python scripts/benchmark.py --compare --device auto --repeats 3
```

Первый запуск включает скачивание весов в `cold_start_seconds`. Для чистого
измерения загрузки из локального cache повторите запуск и сохраняйте оба отчёта
отдельно. Для production передавайте проверенный commit через `--revision`.
